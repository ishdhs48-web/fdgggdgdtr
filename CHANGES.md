## 🚀 Как запустить

1. Распакуйте `new_version.zip` или используйте папку `app`
2. Запустите `start.cmd` (Windows) или `node app/server.mjs`
3. Откройте в браузере: `http://localhost:8770`
4. Для управления ПК нажмите кнопку "ПК Контроль" в sidebar

## 🔧 API для управления ПК

Добавлены новые эндпоинты:
- `GET /api/pc/system` - Системная информация
- `POST /api/pc/execute` - Выполнение команд

Поддерживаемые команды:
- `system_info` - Информация о системе
- `processes` - Список процессов
- `files` - Список файлов
- `network` - Сетевая информация
- Кастомные команды (с проверкой безопасности)
